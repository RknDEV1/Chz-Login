# Achados visuais

A captura atual mostra o `CHZPrivLogo` como um quadrado arredondado com fundo branco, diferente da referência, que usa apenas o wordmark CHZ PRIV sobre fundo preto.

A referência usa: fundo preto; arco vermelho discreto acima do wordmark; CHZ vermelho e PRIV branco, centralizados; subtítulo abaixo; cartão estreito com borda vermelha fina; campo de key e botão OBTER DID em cinza escuro; botão ENTRAR vermelho; suporte com linhas finas; Discord branco dentro de círculo com borda vermelha.

Para a correção, a logo de imagem deve ficar oculta como fallback e o wordmark textual deve ser exibido; o status inicial deve ficar oculto para não criar uma linha extra; o arco superior deve ser fino em vez de uma cápsula oval; o ícone do DID deve usar um símbolo de clipboard; o conteúdo deve respeitar a área segura e manter larguras alinhadas.
